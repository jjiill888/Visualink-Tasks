# VisualLink 设计语言

源头:云笔记模块(ne-*)经用户多轮验收定型的视觉/交互体系。
本文是全系统(笔记 / IM / 内部协作)UI 工作的**约束性规范**,不是参考建议。
关键词:极简、优雅、流畅、高效率、美观、高性能。

## 一、色彩系统(系列统一的根基)

**原则:层级只靠灰阶,颜色只给需要注意的信息。** 强调蓝只用于
当前选中/链接/焦点/协作状态,占屏面积 3~5%;语义色只表达 成功/警告/错误;
其余一律灰阶。永远用变量,禁止写死色值。

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--ne-bg` | `#ffffff` | `#1e1e1e` | 画布 |
| `--ne-fg` | `#1f2329` | `#d8d8d8` | 正文 |
| `--ne-heading` | `#15181d` | `#f0f0f0` | 标题(比正文深/亮半档) |
| `--ne-muted` | `#71767d` | `#969696` | 次级:状态/描述/时间 |
| `--ne-faint` | `#a9afb8` | `#707070` | 装饰:分组标签/占位符 |
| `--ne-line` | `#ebedef` | `#343434` | 常规分隔线 |
| `--ne-line-strong` | `#d7dade` | `#505050` | 强分隔 |
| `--ne-bg-surface` | `#fafafa` | `#191919` | 侧栏/面板(比画布暗半档) |
| `--ne-bg-hover` | `#f2f3f5` | `#292929` | 悬停 |
| `--ne-bg-active` | `#e9ecef` | `#303030` | 激活/按压/选中 |
| `--ne-accent` | `#3873b3` | `#6ea8fe` | 唯一强调蓝(交互态专用) |
| `--ne-accent-hover` | `#2f65a0` | `#82b4ff` | |
| `--ne-accent-muted` | `rgba(56,115,179,.10)` | `rgba(110,168,254,.14)` | 选中项淡底 |
| `--ne-ok` | `#1a7f37` | `#63c174` | 成功/在线 |
| `--ne-warn` | `#9a6700` | `#d6a84b` | 警告 |
| `--ne-err` | `#dc2626` | `#e06c75` | 错误(不用于未读角标) |

**人的颜色 = 协作五色盘**(低饱和):`#6ea8fe / #c58af9 / #63c174 / #e6a65d / #e47785`。
笔记协作光标、IM 群聊用户名等"区分不同的人"的场景共用同一分配算法,
是跨模块系列感的重要来源。禁止另起用户配色。

**模块识别(用户已裁定)**:三模块共用同一强调蓝与全部灰阶,不给每个模块
单独的主题色(彩色分心)。模块身份只体现在 favicon 与顶栏模块切换器的
文字上,不体现在色相上。变量名沿用 `--ne-` 前缀(用户已裁定,不改 --vl-)。

**词元的接入方式**:单一事实来源是 `static/css/ne-base.css`(浅色 `:root`/
深色 `html.ne-dark`),main.go 启动时读入,模板函数 `{{neBaseCSS}}` 内联进
页面 `<head>` 的 `<style>`——新页面接入词元用这个,不要 link 也不要复制色值。

## 二、主题机制

- `html.ne-dark` 类驱动深色(不用 `@media` 写深色规则),`localStorage` 键
  `ne-theme ∈ auto/light/dark` 全系统共享——任一模块切换,处处生效。
- 每页 `<head>` 最前内联预判脚本防闪烁(抄 note_edit.html / notes.html 的)。
- 主题按钮 = 三枚内联 SVG(半圆=自动/太阳=浅色/月亮=深色)常驻 DOM,
  CSS 按 `data-theme` 只显一枚;新页面直接复用这段标记。

## 三、图标铁律

不引入任何图标库/图标字体。只允许两种做法:
1. **内联 SVG**:`stroke="currentColor"`、`stroke-width≈1.8`、`viewBox="0 0 24 24"`、
   盒 16px(与 14px 中文字视觉等高),跟随 `.ne-link` 的悬停变色。
2. **CSS mask + data URI**:`background: currentColor`,单条规则共享零 DOM,
   适合列表行首等重复图标(侧栏文件树是范例)。

## 四、交互准则(经用户多轮反馈定型)

- **最少点击数**:状态切换用单击循环(如 公开→私有→受限),悬停展开菜单
  之类的"先悬停再点"方案已被否决。
- **零视觉噪音**:无常亮彩色状态标记;能一眼从文字读出的状态不加颜色。
- **禁原生控件**:radio/select/带边框 input 一律不用;档位=一行文字按钮
  (当前项 `.ne-on` 蓝),开关=双词点切,输入框=无边框(文库搜索样式)。
- **次要操作悬停浮现**:删除/回复等挂 hover 显示;`(hover:none)` 环境回退常显。
- **顶栏语言**:40px、按钮 `.ne-link`(默认 opacity .65,栏悬停全亮)、
  统一 24px 盒高、图标下沉 1px 光学对齐;`.ne-right` gap 8px——
  中文标签方正紧凑,间距宁紧勿松。
- **安静的状态栏**:一切正常时什么都不显示;只在多人在线/离线暂存等
  需要用户知道的时刻出一行浅灰小字。

## 五、组件惯用法

- 页面骨架:独立页(不套 base.html 旧外壳),`renderStandalone` + 专属模板集,
  `body.note-standalone` 类作用域;新模块页跟随此模式。
- 侧栏/面板:`--ne-bg-surface` 底,VSCode 式行(悬停 `--ne-bg-hover`、
  选中 `--ne-accent-muted` 底 + `--ne-accent` 文字),可折叠组头旋转箭头,
  折叠状态存 localStorage。
- 列表页:一行一条 + 悬停浮现操作 + 无边框搜索(ne-lib-* 是范例)。
- 弹层:文字按钮组 + 描述行浅灰,`:empty` 防闪空框,HTMX 换整板。
- 消息流(IM 方向):**不用气泡**——扁平行(名字着五色盘 + 时间 `--ne-faint`
  + 正文 `--ne-fg`),自己的消息不做特殊配色,悬停整行浮现操作。
- 细滚动条已有全局样式,勿重做。

## 六、性能要求

- 依赖最少:htmx + Alpine + 原生 JS,不引前端框架;新功能先问"能不能不加包"。
- 静态资产:内容 hash `?v=`、br 预压缩、immutable;大资产懒加载/ESM 分割
  (协作 chunk 模式);跨境高 RTT 是常态,首屏阻塞资源只留必需 CSS。
- 预取:列表页 prefetch 编辑器资产;Speculation Rules 悬停预取
  (**必须排除有副作用的 GET,如 /notes/new**)。
- 实时:SSE 已有统一通道(/sse),新实时特性优先挂现有事件流。
